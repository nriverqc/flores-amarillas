Una aplicación web interactiva, moderna, cálida y optimizada para dispositivos móviles creada como un detalle especial para **Lorena** con motivo del **21 de septiembre (Día de las Flores Amarillas)**.

El tono de la experiencia refleja la belleza de ir conociéndose poco a poco: con calma, buena vibra, respeto y el gusto genuino de compartir tiempo y risas juntos.

---

## ✨ Características de la Experiencia

* 🌻 **Hero Especial para Lorena:** Título *"Flores Amarillas para Lorena 🌼"* y subtítulo *"Un pequeño detalle para celebrar este 21 de septiembre"*, con girasol interactivo que florece al tacto.
* 📱 **Optimización Mobile-First:** Diseñada y adaptada para cualquier pantalla de smartphone (320px a 430px), con áreas táctiles generosas (mínimo 44x44px), tipografías legibles y sin desplazamientos horizontales.
* 💐 **Jardín con 4 Flores y Notas Sinceras:**
  * **Girasol (Un detalle especial):** Alegría, buena energía y el deseo de sacarle una sonrisa en este día.
  * **Rosa Amarilla (Paso a paso):** La calma, la buena vibra y el gusto de conocerse sin prisas.
  * **Tulipán (Un buen comienzo):** Nuevos comienzos, sorpresas gratas y entusiasmo sincero.
  * **Margarita (Interés genuino):** La espontaneidad, las risas compartidas y la motivación de ver a dónde lleva el camino.
* 💌 **Cartas Modales con Sello de Cera:** Con diseño de sobre y pergamino, botón táctil de cierre rápido, botón para copiar y firma:
  > *Con cariño, Nicolas Rivera ✨*
* 🎶 **Sintetizador Web Audio API Nativo:** Acordes sutiles y notas de celesta en el navegador sin archivos externos pesados.
* 🍃 **Lluvia Interactiva de Pétalos:** Canvas HTML5 a 60 FPS con física suave y respuesta al tacto o cursor.
* 🎉 **Lluvia de Confeti Dorado:** Gatillo de celebración con partículas doradas y pétalos.
