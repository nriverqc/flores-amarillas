Una aplicación web interactiva, moderna, cálida y optimizada para dispositivos móviles creada como un detalle especial para **Lorena** con motivo del **21 de septiembre (Día de las Flores Amarillas)**, con integración de invitación a cita interactiva mediante **EmailJS**.

---

## ✨ Características Principales

* 🌻 **Hero Especial para Lorena:** Título *"Flores Amarillas para Lorena 🌼"* y subtítulo *"Un pequeño detalle para este 21 de septiembre"*, con girasol interactivo SVG que florece al tacto.
* 💐 **Jardín con 4 Flores y Cartas Sinceras:**
  * **Girasol (Flores eternas):** Creadas en código para que nunca se marchiten.
  * **Rosa Amarilla (Interés sincero):** La honestidad de admitir que a veces los tiempos no cuadran, pero el interés es totalmente real.
  * **Tulipán (Desde la fiesta):** El recuerdo bacano de la fiesta de la prima y las ganas de organizar la primera salida solo los dos.
  * **Margarita (Hecho a tu medida):** Un detalle creado pensando únicamente en ella.
* 🍦 **Invitación a Salida Integrada con EmailJS:**
  * Propuesta: *"¿Te suena un helado o caminar un rato este miércoles en la tarde en el Parque Gilma Jiménez?"*
  * **Opción A (Aceptar):** Notifica automáticamente a Nicolas por correo con EmailJS y activa confeti con mensaje de confirmación.
  * **Opción B (Sugerir otro lugar):** Formulario para que Lorena proponga otro lugar en la tarde y lo envíe directamente a Nicolas.
* 📱 **Mobile-First Responsiveness:**
  * Optimizado para pantallas móviles (320px a 430px) sin desbordamientos horizontales.
  * Áreas táctiles generosas de mínimo 44x44px.
* 🎶 **Sintetizador Web Audio API Nativo:** Sonidos de celesta y arpas sutiles sin archivos MP3 externos.
